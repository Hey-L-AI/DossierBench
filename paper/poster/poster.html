1Recall misses invented preferences

A profile that invents a preference misleads the recommender on every later suggestion. Recall tests can’t see it.

We score calibration: commit only where the conversation gives grounds, abstain everywhere else.

3Simple extractors calibrate well

Switching the model moves skill over 5× more than switching prompted for notebook.

The memory layer scores lower at twice the calls.

4Main failure: committing too early

Half to three-quarters of mistakes are guesses made before any evidence. The guess is right at most 17% of the time.

The guess is usually the middle of the scale: “notices value”, “fine with lively”.

Every model trips on the same cues: “a proper table rather than perching” becomes the hard constraint seating_required.

The memory layer also loses what it knew: errors flicker wrong, right, wrong.

Score whether a profile knows when it doesn’t know.
Committing before the evidence arrives is the main failure.
Simple single-pass extractors beat a memory layer here.
